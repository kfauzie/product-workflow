# Product glossary: Relaywise

> **FICTIONAL EXAMPLE.** Relaywise, Relay Agent, Relay Studio and Pellmore are invented. The use case and all data are synthetic. Any resemblance to a real company is unintended.

| Term | Plain meaning | Unit | Where it appears | Don't confuse with |
|---|---|---|---|---|
| Ticket category | A type of customer request, e.g. "Billing disputes" | — | Data, screens | A support queue |
| Auto-resolve | The AI answers and closes the ticket on its own | — | Screens | Auto-reply (a canned acknowledgement) |
| AI drafts, agent approves | The AI writes the answer; an agent checks and sends it | — | Screens | Auto-resolve |
| Escalated | The AI wasn't sure, so it passed the ticket to an agent | % of tickets | Data | A wrong answer |
| Shadow mode | The AI answers past tickets without sending; agents grade each answer | — | Data | A live pilot |
| Accuracy | Correct answers ÷ tickets the AI answered | % | Data, screens | Resolution rate |
| "At least" accuracy | The lower end of a 95% confidence range, so small samples count for less | % | Screens | The average |
| Serious wrong answer | A wrong answer that costs real money: a wrong refund, an escalation | £400 each (estimate) | Screens | A minor wrong answer (customer just contacts again, £15) |
| Handle time | Agent minutes per ticket | Minutes | Data | Reply time |
