# Design system: Relaywise

> **FICTIONAL EXAMPLE.** Relaywise, Relay Agent, Relay Studio and Pellmore are invented. The use case and all data are synthetic. Any resemblance to a real company is unintended.

Figma isn't connected in this example, so these values stand in for what the Figma MCP would return.

| Role | Value |
|---|---|
| Main action | Teal #0f766e (one per screen) |
| Text / headings | Grey #343a40 / #212529 |
| Background / panels | Off-white #f9f9fa / white |
| Status tints | Green done, amber needs attention, blue selected or informational |
| Font | Inter, Arial as fallback |
| Logo | Wordmark "RELAYWISE", product name after it in lighter weight |
| Voice | Plain and confident. Lead with the saving and the risk. Every percentage says what it's out of |
| Copy checklist | Outcome first? Numbers with what they're out of? Term matches the glossary? Risk stated next to the saving? |
