# 8. MVP review (pm-6)

> **FICTIONAL EXAMPLE.** Relaywise, Relay Agent, Relay Studio and Pellmore are invented. The use case and all data are synthetic. In a real run these pages live in Notion; here they are Markdown so the workflow can be read end to end.

**What we need to test:** that the recommended mode per category matches what the team would decide, and that the AI's shadow-mode grades match agent judgement. About 50 graded tickets per category, including tricky ones.

1. Could you have used this brief when you switched Order status on? What would you have done differently?
2. What would your VP and Finance need to see before approving the pilot?
3. Could you send us 50 or so recent tickets per category that your agents found hard, with the answer they sent? Please include a few refunds and a few where the customer came back.
4. Would Finance accept £400 as the cost of a serious wrong answer, or does it need their own figure?
5. Is "3 of the last 50 answers reversed" the right point to switch a category off?
6. *(Optional)* By default, auto-resolve needs 100 graded tickets, 95% accuracy at the lower bound and at most 0.5% serious errors. Would your team use the same bar?
