# Design system: Gusta

> **FICTIONAL EXAMPLE.** Kestrel, Gusta, the use case and all data are synthetic. Any resemblance to a real company is unintended.

Figma isn't connected in this example, so these values stand in for what the Figma MCP would return.

| Role | Value |
|---|---|
| Accent | Teal #0f766e, sparingly |
| Text / headings | Grey #343a40 / #212529 |
| Background / panels | Off-white #f9f9fa / white |
| Status | Green AI, amber AI-assisted human, red Human; always with the words, never colour alone |
| Font | Inter, Arial as fallback |
| Voice | Plain and specific. No marketing phrasing, no buzzwords |
