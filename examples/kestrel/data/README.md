# Data (FICTIONAL)

Synthetic data for the fictional Kestrel example (customer: Gusta), made by `../notebooks/make_data.py`. No real company, customer or ticket.

- `ticket_types.json`: the 16 ticket types (15 named, plus Other for tickets that match none), their volumes, accuracy, impact if wrong and 3 recent tickets each
- `support_playbook.md`: Gusta's support playbook. Every example quotes the rule it was graded against, by ID

The playbook rules, tickets and impact lines follow how UK payroll support works in practice (BACS timings, HMRC submissions, starter checklists, auto-enrolment, holiday pay rules), modelled on public UK payroll help-centre articles and gov.uk guidance. All wording is paraphrased and fictional; no real product's text or menus are copied.
