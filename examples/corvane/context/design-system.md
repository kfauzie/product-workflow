# Design system: Corvane

> **FICTIONAL EXAMPLE.** Corvane, Riskline, Retrofit Planner, Ashgrove Partners, Project Lantern and Lantern Group are invented. All data is synthetic. Any resemblance to a real company is unintended.

Figma isn't connected in this example, so these values stand in for what the Figma MCP would return.

| Role | Value |
|---|---|
| Main action | Indigo #4338ca (one per screen) |
| Text / headings | Grey #343a40 / #212529 |
| Background / panels | Off-white #f9f9fa / white |
| Positive / done | Green #15803d, sparingly |
| Status tints | Green done, amber needs attention, blue selected or informational |
| Font | Inter, Arial as fallback |
| Logo | Wordmark "CORVANE", product name after it in lighter weight |
| Voice | Expert, plain, confident. Lead with the financial outcome. Every grade or score says what it means. No alarmist framing |
| Copy checklist | Outcome first? Specific numbers and hazards? Term matches the glossary? No unexplained scores? |
