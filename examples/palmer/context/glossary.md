# Product glossary: Palmer

> **FICTIONAL EXAMPLE.** Palmer, the use case and all data are synthetic. Any resemblance to a real company is unintended.

| Term | Plain meaning | Unit | Don't confuse with |
|---|---|---|---|
| Ticket type | A kind of request, e.g. "Password reset" | | A support queue |
| Resolve alone | The agent answers or acts and closes the ticket without a person | | Auto-reply |
| Draft for approval | The agent drafts the reply or action; a person approves it | | Resolve alone |
| Human only | The agent doesn't touch the ticket | | Escalation after a wrong answer |
| Accuracy | Share of 50 past tickets of a type that the agent got right, graded by the support team | % | Customer satisfaction |
| Cost of a wrong call | What a wrong answer would cost the customer: Low, Medium or High | | The price of the ticket |
| Moves money | The ticket can change a payment: refunds, payroll runs, bank details, pay dates | | Billing questions |
